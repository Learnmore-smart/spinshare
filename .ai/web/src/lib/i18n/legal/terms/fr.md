# terms/fr.tsx

French translation of `web/src/lib/i18n/legal/terms/en.tsx`.

- Export: `TermsBodyFr({ titles })` — section titles from dictionary props.
- Mirrors EN structure: `LegalSection` / `LegalSubsection`, `codeClass` for inline code.
- Registered in `terms/index.tsx` for locale `fr`.
- Generated via `scripts/translate_terms_fr.py` from `scripts/terms_fr_sections.py` (22 sections, 106 subsections, 543 lines).
- All user-visible body text in French; emails and product names preserved.
- Sections 1–2 complete; sections 3–22 appended via PowerShell UTF-8 `AppendAllText` (2026-06-14).
- Terminology: « Contrat », temps d&apos;attente IA, Gains, Enchère/Offre, Limite de vélocité.
