# .env

> Last updated: 2026-06-16 | Protection: CRITICAL

## Purpose

Local runtime configuration for the SpinShare web app, extension, Stripe test
checkout, Firebase/Firestore, RTDB counters, and OAuth.

## What It Does

- Selects local vs production mode.
- Selects mock/test/live Stripe behavior.
- Selects OAuth vs mock auth.
- Provides local callback URLs.
- Stores sensitive provider credentials. Do not copy secret values into docs or
  chat output.

## Important Notes / NEVER Change

- Do not print or document secret values.
- Local real Stripe (`STRIPE_MODE=test|live`) must not use memory durable repos,
  because paid checkout records can disappear between redirect/webhook/dashboard
  requests.
- Local cloud Firestore writes must use `SPINSHARE_FIRESTORE_NAMESPACE`, usually
  `test`, to avoid mutating top-level production collections.
- Pure localhost sample ads can still use `STRIPE_MODE=mock` and memory storage.

## Planned Change 2026-06-16

Set the current local Stripe test environment to durable namespaced Firestore:

- `SPINSHARE_USE_FIRESTORE=1`
- `SPINSHARE_FIRESTORE_NAMESPACE="test"`

This matches the product decision that localhost Stripe tests should write to a
test namespace instead of actual top-level Firestore collections or process
memory.

## Implemented Change 2026-06-16

The local `.env` now sets `SPINSHARE_USE_FIRESTORE=1` and
`SPINSHARE_FIRESTORE_NAMESPACE="test"` while leaving all secret values
unchanged.
