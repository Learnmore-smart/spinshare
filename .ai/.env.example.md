# .env.example

> Last updated: 2026-06-14 | Protection: STANDARD

## Purpose
Documents required and optional environment variables without storing secret values.

## What It Does

- Shows local and production mode flags.
- Lists Firebase, Stripe, OAuth, NextAuth/Auth.js, and CLI client variables.
- Provides placeholder values safe to commit.

## Public API

| Name | Type | Description |
|------|------|-------------|
| Environment variable placeholders | text | Non-secret template copied to `.env` or CI secret configuration. |

## Props / Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| N/A | N/A | N/A | Template file only. |

## Dependencies

- **Internal:** `web/src/server/container.ts` - consumes provider selection flags.
- **Internal:** `cli-wrapper/src/api-client.ts` - consumes CLI base URL/token variables.
- **Internal:** `web/src/server/adapters/firestore/client.ts` - consumes Firebase Admin variables.
- **Internal:** `web/src/server/adapters/stripe/stripe-gateway.ts` - consumes Stripe variables.
- **Internal:** `web/src/server/adapters/auth/nextauth-config.ts` - consumes OAuth/Auth.js variables.

## Important Notes / NEVER Change

- Never put real secrets in this file.
- Keep this file synchronized when adding or removing environment variables.
- **Single `.env` at repo root.** Copy this template to `.env` at the repository root. Next.js loads it via `loadEnvConfig` in `web/next.config.mjs` — no `web/.env` file or symlink needed.
- Do not maintain a separate `web/.env` with different OAuth or mode flags — that caused `deleted_client` when root and web files diverged.
